# Rebase & History

<Callout type="info">
এই page এ শিখবে কীভাবে branch আপডেট রাখা যায়, commit history পরিষ্কার করা যায়, আর নির্দিষ্ট commit খুঁজে বের করা বা অন্য branch এ নেওয়া যায়।
</Callout>

## What Is This

Rebase & History মানে Git এর commit history নিয়ে কাজ করার কমান্ড গুলো। এর ৪টা মূল টুল:

- `git rebase` — branch কে অন্য branch এর নতুন অবস্থার উপর তুলে আনে
- `git rebase -i` — commit গুলো squash/reword/drop করে পরিষ্কার করে
- `git cherry-pick` — একটা নির্দিষ্ট commit অন্য branch এ কপি করে
- `git bisect` — কোন commit এ bug ঢুকেছে সেটা দ্রুত খুঁজে বের করে

## Why Need This

Team এ কাজ করলে branch পুরনো হয়ে যায়, commit history এলোমেলো হয়ে যায়, আর মাঝে মাঝে একটা fix অনেক জায়গায় লাগাতে হয়। এগুলো সামলাতে না পারলে:

- Reviewer PR এ messy commit history দেখে বিরক্ত হয়
- একই fix বারবার আলাদা করে লিখতে হয়
- Production এ bug এলে root cause খুঁজতে ঘণ্টার পর ঘণ্টা লাগে

এই কমান্ড গুলো জানলে history পরিষ্কার থাকে আর সমস্যা দ্রুত সমাধান করা যায়।

## Step by Step + Use Case

<Steps>

### Step 1 — Branch কে আপডেট রাখা

Use case: তুমি ৪ দিন ধরে একটা feature branch এ কাজ করছ। এর মধ্যে team `main` এ অনেক commit যোগ করেছে। Reviewer বলেছে "rebase করে দাও, merge commit চাই না।"

```bash filename="Terminal"
git fetch origin
git switch feature/price-filter
git rebase origin/main
```

Git তোমার প্রতিটা commit `main` এর সর্বশেষ অবস্থার উপর একটা একটা করে বসিয়ে দেয়। History সোজা একটা লাইন হয়ে যায়, কোনো merge commit থাকে না।

<Callout type="warning">
যে branch এ অন্য কেউ কাজ করছে (`main`, `develop`, `staging`), সেটা কখনো rebase করবে না। Rebase commit এর hash বদলে দেয় — teammate দের কাছে পুরনো hash থাকলে history এলোমেলো হয়ে যাবে। শুধু নিজের branch rebase করো।
</Callout>

Conflict এলে file ঠিক করে `git add` করো, তারপর:

```bash filename="Terminal"
git rebase --continue
```

আটকে গেলে পুরোটা বাতিল করতে পারো, কিছু হারাবে না:

```bash filename="Terminal"
git rebase --abort
```

### Step 2 — Rebase করা branch push করা

Use case: rebase করার ফলে commit hash বদলে গেছে, কিন্তু GitHub এ আগের commit গুলো এখনো আছে। সাধারণ `push` এখন কাজ করবে না।

```bash filename="Terminal"
git push --force-with-lease
```

`--force` না লিখে `--force-with-lease` লেখো। এটা push করার আগে চেক করে remote branch কেউ বদলেছে কিনা — বদলে থাকলে push আটকে দেয়, teammate এর কাজ মুছে যায় না।

<Callout type="warning">
Force push ভুল জায়গায় হলে team এর কয়েক দিনের কাজ মুছে যেতে পারে। গুরুত্বপূর্ণ repository তে GitHub এ Branch protection চালু রাখো — Settings → Branches → `main` এর জন্য "Do not allow force pushes" অন করো।
</Callout>

### Step 3 — Messy commit পরিষ্কার করা

Use case: PR পাঠানোর আগে দেখলে ৫টা commit — "wip", "fix typo", "fix again" এর মতো এলোমেলো। Reviewer কে একটা পরিষ্কার commit দেখাতে চাও।

```bash filename="Terminal"
git rebase -i HEAD~5
```

Editor খুলবে, প্রতিটা commit এর পাশে `pick` লেখা থাকবে। যেগুলো আগেরটার সাথে জুড়ে দিতে চাও, সেগুলোর `pick` বদলে `fixup` লেখো (message বাদ যাবে):

```
pick   8b2e4a6 add filter api endpoint
fixup  2c8b5d3 wip
fixup  7b3d8e1 fix typo
```

Save করে বন্ধ করলেই commit গুলো এক হয়ে যাবে।

### Step 4 — একটা নির্দিষ্ট commit অন্য branch এ নেওয়া

Use case: `hotfix/payment` branch এ একটা bug fix করে `main` এ merge করেছ। এখন `develop` branch এও এই fix লাগবে, কিন্তু পুরো `main` merge করা যাবে না — অন্য অসম্পূর্ণ কাজও চলে আসবে।

```bash filename="Terminal"
git log --oneline main -3      # fix এর commit hash বের করো
git switch develop
git cherry-pick <commit-hash>
git push
```

শুধু ওই commit এর change টুকু `develop` এ একটা নতুন commit হিসেবে যোগ হয়।

### Step 5 — কোন commit এ bug ঢুকেছে খুঁজে বের করা

Use case: QA বলল checkout page ভাঙা। দুই সপ্তাহ আগে ঠিক ছিল, এর মধ্যে ২০০টা commit হয়েছে। একটা একটা করে দেখলে সারাদিন লাগবে।

```bash filename="Terminal"
git bisect start
git bisect bad                  # এখনকার অবস্থা ভাঙা
git bisect good v2.3.0          # এই tag এ ঠিক ছিল
```

Git এখন মাঝামাঝি একটা commit এ নিয়ে যায়। App চালিয়ে test করো, তারপর বলো:

```bash filename="Terminal"
git bisect good     # অথবা
git bisect bad
```

কয়েকবার পরীক্ষার পর Git বলে দেয় কোন commit এ bug ঢুকেছে। শেষে অবশ্যই এটা চালাও, নাহয় আটকে থাকবে:

```bash filename="Terminal"
git bisect reset
```

</Steps>
