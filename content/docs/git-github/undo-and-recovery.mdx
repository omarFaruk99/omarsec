# Undo & Recovery

<Callout type="info">
Git এ ভুল করা কোনো সমস্যা না — প্রায় সবকিছুই ফেরানো যায়। এই page এ শিখবে কোন পরিস্থিতিতে কোন কমান্ড ব্যবহার করবে।
</Callout>

## What Is This

Undo & Recovery মানে Git এ ভুল হলে সেটা ঠিক করার উপায়। এর জন্য ৪টা মূল কমান্ড লাগে:

- `git restore` — file এর পরিবর্তন বাতিল করে
- `git reset` — commit বাতিল করে
- `git revert` — push করা commit বাতিল করে, safe ভাবে
- `git reflog` — হারানো কাজ খুঁজে বের করে

## Why Need This

কাজ করতে গিয়ে ভুল হবেই — ভুল file এ change, ভুল commit message, এমনকি ভুল branch এ push। সঠিক কমান্ড না জানলে দুইটা সমস্যা হয়:

- ভয়ে কিছু করতে পারবে না, কাজ আটকে থাকবে
- ভুল কমান্ড দিয়ে সমস্যা আরও বড় করে ফেলবে — যেমন push করা commit এ `reset` চালিয়ে দেওয়া

তাই ভুলটা কোন ধাপে আটকে আছে সেটা চেনা, আর সেই অনুযায়ী সঠিক কমান্ড বেছে নেওয়াই এই page এর কাজ।

## Step by Step + Use Case

তোমার কাজ Git এ ৪টা ধাপের যেকোনো একটায় থাকতে পারে। কোন ধাপে আছে সেটাই ঠিক করে দেয় কোন কমান্ড লাগবে।

<Steps>

### Step 1 — File এর change বাতিল (commit করোনি)

Use case: একটা file এ change করেছ, কিন্তু এখন সেটা রাখতে চাও না।

```bash filename="Terminal"
git restore file.js
```

File আগের (last commit) অবস্থায় ফিরে যায়।

### Step 2 — Staged change বাতিল

Use case: `git add` করেছ, কিন্তু commit করোনি। Add করা বাতিল করতে চাও, change মুছতে চাও না।

```bash filename="Terminal"
git restore --staged file.js
```

### Step 3 — Commit বাতিল (push করোনি)

Use case: commit করেছ, কিন্তু GitHub এ push করোনি। এই commit রাখতে চাও না।

```bash filename="Terminal"
git reset --soft HEAD~1
```

`--soft` দিলে code হারায় না, শুধু commit-টা খুলে যায়। পুরো code-সহ মুছে দিতে চাইলে:

```bash filename="Terminal"
git reset --hard HEAD~1
```

<Callout type="warning">
`--hard` code সরাসরি মুছে দেয়। নিশ্চিত না হলে `--soft` ব্যবহার করো।
</Callout>

### Step 4 — Push করা commit বাতিল

Use case: commit GitHub এ push হয়ে গেছে, হয়তো teammate রা pull-ও করে ফেলেছে।

এখানে `reset` ব্যবহার করবে না — তাতে সবার history আলাদা হয়ে যায়। বদলে `revert` ব্যবহার করো:

```bash filename="Terminal"
git revert HEAD
git push
```

এটা পুরনো commit মোছে না, বরং তার উল্টো একটা নতুন commit বানায়। History ঠিক থাকে।

### Step 5 — হারানো কাজ ফিরিয়ে আনা

Use case: ভুল করে `reset --hard` দিয়েছ, বা branch delete করে ফেলেছ। কাজ হারিয়ে গেছে মনে হচ্ছে।

```bash filename="Terminal"
git reflog
```

এই কমান্ড দেখায় তুমি আগে কোথায় কোথায় ছিলে। সেখান থেকে হারানো commit এর hash নিয়ে ফিরিয়ে আনো:

```bash filename="Terminal"
git reset --hard <commit-hash>
```

<Callout type="info">
`reflog` শুধু তোমার নিজের কম্পিউটারে থাকে, ৩০-৯০ দিন পর মুছে যায়। আর commit না করা কাজ এখানে নেই — সেটা `reset --hard` করলে চিরতরে হারায়।
</Callout>

</Steps>

## Real-World Note

<Callout type="warning">
`.env` file ভুলে push হয়ে গেলে শুধু `reset --hard` করে মুছলেই হয় না — commit-টা GitHub এ থেকেই যায়, direct link দিয়ে পড়া যায়। আগে key/password rotate (বদলে ফেলা) করো, তারপর file track থেকে বাদ দাও।
</Callout>
