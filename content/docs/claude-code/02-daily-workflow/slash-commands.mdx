# Slash Commands

<Callout type="info">
Commands that start with `/`. They only work at the start of a message.
</Callout>

## How to Use Them

Type `/` inside a session to see the full list. Type `/` plus a few letters to filter it.

## The Ones You Use Most

| Command | What it does |
|---------|---------------|
| `/plan` | Explore and plan before making changes |
| `/model` | Switch the AI model (Sonnet, Opus, Haiku) |
| `/compact` | Shorten the chat to free up space |
| `/clear` | Start a new chat, keep project memory |
| `/context` | See how full the context window is |
| `/resume` | Go back to an earlier session |
| `/diff` | See your uncommitted code changes |
| `/code-review` | Scan your changes for bugs |
| `/init` | Create a `CLAUDE.md` for this project |
| `/memory` | View or edit project memory |
| `/permissions` | Set which tools need approval |
| `/help` | Show all available commands |

## A Few More Worth Knowing

- `/status` — shows your version, model, and account
- `/export` — saves the chat as a text file
- `/doctor` — checks if your setup is healthy
- `/feedback` — report a bug

<Callout type="default">
You do not need to memorize all of them. Start with `/plan`, `/model`, `/compact`, and `/code-review` — the rest you will pick up as you need them.
</Callout>
