# AWS SES

<Callout type="info">
এই section তাদের জন্য যারা নিজের bulk email সিস্টেম বানাতে চান — কোনো কোড লেখা লাগে না, তাই এটা Developer-এর কাজ না। owner/admin নিজেই AWS SES, domain, আর DNS সেটআপ করে Developer-কে হ্যান্ডওভার করতে পারেন। তবে AWS console, DNS record, আর টার্মিনোলজির সাথে কিছুটা পরিচিত থাকা দরকার — ধাপগুলো মনোযোগ দিয়ে অনুসরণ করতে হবে।
</Callout>

## এই Section কেন

কোনো কোম্পানি যখন নিজের সার্ভার থেকে বাল্ক ইমেইল (marketing/product update) পাঠাতে চায়, তখন Gmail/Yahoo-র কাছে বিশ্বাসযোগ্য হতে হলে **AWS SES**, **domain ownership প্রমাণ (DKIM/SPF/DMARC)**, আর সঠিক DNS সেটআপ লাগে। এই section সেই পুরো প্রসেসটা ধাপে ধাপে দেখায় — AWS console-এর ভেতরে ঠিক কোথায় ক্লিক করতে হবে, সহ।

## Prerequisites

- একটা ইমেইল এড্রেস
- একটা কার্ড ও ফোন নাম্বার (AWS account খুলতে দুইটাই ভেরিফাই করা লাগে)
- ডোমেইন কেনার টাকা (একটা ডোমেইন প্রতি বছর প্রায় $10-15)

Developer হওয়া বা কোড জানা দরকার নেই — কিন্তু AWS console-এ ধাপে ধাপে সাবধানে কাজ করতে হবে, তাড়াহুড়া করলে ভুল হতে পারে।

## What You Will Learn

- **AWS Account:** AWS account খোলা, region বাছা, SES-এ প্রথম টেস্ট মেইল পাঠানো
- **Domain & DNS:** নিজের domain SES-এ verify করা, DKIM/SPF/DMARC রেকর্ড Cloudflare-এ বসানো
- **Sending Credentials:** কোড থেকে মেইল পাঠানোর জন্য Access Key বা SMTP credential বানানো
- **Production Access:** Sandbox থেকে বের হয়ে আসল ক্লায়েন্টদের মেইল পাঠানোর অনুমতি নেওয়া, sending quota বোঝা
- **Developer Handover:** Developer-কে যা যা নিরাপদে হ্যান্ডওভার করতে হবে

## How to Use This Section

<Callout type="warning">
প্রতিটা ধাপ AWS console-এর real screen দেখে verify করা — কিন্তু AWS console মাঝে মাঝে UI বদলায়, তাই লেখা navigation-এর সাথে সামান্য পার্থক্য দেখলে ঘাবড়াবেন না, সাধারণত একই জায়গায় বা কাছাকাছি নামে থাকে।
</Callout>

<Callout type="default">
