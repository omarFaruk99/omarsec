# Docker Production Guide

<Callout type="info">
Frontend, backend, আর database — এই তিনটা নিয়ে একটা রিয়েল অ্যাপ Docker দিয়ে প্রোডাকশনে চালাতে যা লাগে, এই গাইডে তাই আছে। কোর্স না — সরাসরি কাজে লাগার মতো।
</Callout>
